Blackjack in Python

A console card game built around reusable classes and game rules

Project overview

I created a playable, console-based Blackjack game in Python for one player and an automated dealer. The game models cards, decks, and players as separate classes, then brings them together to handle a round of play.

Game features

  • Player and dealer turns, with the dealer standing on soft 17.
  • A betting system with win, loss, and push outcomes.
  • Natural Blackjack handling and a 3:2 payout.
  • Flexible Ace values and deck reshuffling when fewer than 20 cards remain.
  • Separate Card, Deck, and Player classes with docstrings.

Tools and techniques

  • Python 3: game flow, input/output, and control logic.
  • Object-oriented design: organizing card, deck, and player behavior into classes.
  • Rule handling: evaluating hands, bets, and round outcomes.

What I learned

This project strengthened my understanding of object-oriented programming and stateful game logic. I practiced accounting for edge cases such as variable Ace values, ties, natural Blackjack, and reshuffling. A graphical interface or support for multiple players could be future extensions.
