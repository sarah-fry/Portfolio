Ecosystem Simulator in Java

Modeling interactions and change in a small simulated ecosystem

Project overview

I built a Java simulation in which a population of organisms changes over discrete time steps. The project uses an object-oriented model to give different species their own behaviors while an ecosystem manages the population and advances the simulation.

How it works

Each step processes the creatures that are currently alive, applies their behavior, collects new offspring, removes dead organisms, and periodically grows plants. Separate classes represent the ecosystem, plants, and species such as sagebrush voles, ferruginous hawks, and carrion beetles.

  • Used an abstract Species superclass with species-specific subclasses.
  • Modeled creature lifecycle behaviors, including aging, energy changes, and reproduction.
  • Managed births and removals between simulation steps to avoid changing the population during iteration.
  • Added chance-based behaviors and random name generation from a text file.

Tools and techniques

  • Java: classes, inheritance, and polymorphism.
  • Collections: lists for tracking the population, new offspring, and organisms to remove.
  • Simulation logic: discrete time steps and probability-driven behavior.

What I learned

This project gave me practice designing class relationships and coordinating state changes in a simulation. It also helped me think about how to structure behavior so the ecosystem can support different kinds of organisms. Future extensions could add predator-prey interactions or a visual representation of the environment.
