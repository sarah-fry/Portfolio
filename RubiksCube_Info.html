Rubik's Cube Simulation in Java

Representing a cube, applying moves, and tracking state

Project overview

I built a Java program that represents a 3×3 Rubik's Cube and lets a user apply face rotations. The program keeps a history of moves and prints the cube state in the console.

How it works

  • Stored the six faces as a three-dimensional character array.
  • Implemented clockwise and counterclockwise face rotations.
  • Accepted moves through interactive input or command-line arguments.
  • Tracked moves in a list and printed them in reverse order as a sequence to undo the recorded moves.
  • Displayed the cube in a formatted console layout.

Tools and techniques

  • Java 17: program structure and move logic.
  • Multidimensional arrays: storing and updating face layouts.
  • Scanner and command-line arguments: supporting interactive and automated input.
  • ArrayList: tracking the sequence of moves.

What I learned

This project gave me practice with array indexing, spatial reasoning, and managing a changing program state. It also made it clear that printing a reverse move history is only a starting point for solving a cube; a more complete version could add move inverses, scrambling, and solving algorithms.
